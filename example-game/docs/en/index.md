Sample Engine is made up: it fills this template to show the docs in the demoscene look. A project writes its own pages here, one folder per language.

:::note[Sample]
The engine, its API and its numbers do not exist.
:::

## What the template has

- A home page of the project's own, in `src/components/Home.astro`, built from the package's demoscene pieces.
- Docs, search, the header and the footer from the settings, always dark.
